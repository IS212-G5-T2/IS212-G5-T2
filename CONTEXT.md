# Event and Venue Planning

This glossary defines the event and venue terms used when coordinators and venue readers review schedules and requests.

## Language

**Venue schedule browse mode**:
A view of a venue's bookings, holds, unavailable periods and free time that is not attached to an event and cannot create a booking request.

**Event-linked booking mode**:
A view of one assigned event's venue needs and time, used by its Coordinator to request a venue booking.

**Active venue request**:
A pending or confirmed request that still represents an event's current venue arrangement. A cancelled request remains historical information but is no longer active.
