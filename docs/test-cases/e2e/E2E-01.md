# E2E-01: Golden path, single venue (SPM-36, SPM-37, SPM-123, SPM-77, SPM-40, SPM-88, SPM-148, SPM-50, SPM-52, SPM-51, SPM-54, SPM-55, SPM-56, SPM-57, SPM-58, SPM-137, SPM-172, SPM-129, SPM-130, SPM-131, SPM-135, SPM-139, SPM-61, SPM-94, SPM-97)

Cross-role end-to-end test (executed in CI on 2026-11-06, PR #128). P0. Covers the whole planning lifecycle for one event at one venue: the Organiser drafts and submits, the Lead assigns from the unassigned queue, the assigned Coordinator approves, books the venue and requests equipment, Venue Staff approve the booking, Technical Support reserve the equipment, the Safety Officer approves, the Coordinator confirms, and an Attendee registers. It is E2E rather than cheaper because it is the only journey that proves all seven roles hand the same event to one another, that each step notifies the right person and nobody else, that the calendar shows the full occupied window including setup and turnaround, and that equipment availability drops for an overlapping slot.
