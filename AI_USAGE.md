# AI Usage Log

AI-assisted work is filed by Jira ticket in the [archive index](docs/archived/README.md). Work without a single ticket is in [general.md](docs/archived/general.md).

For a new Jira ticket, create `docs/archived/<ticket-key>.md` and add its link to the archive index. Add new entries to the ticket file or `general.md`, not this index.

Add future work under one date per day in the relevant file, using this format:

```md
## YYYY-MM-DD

- <user or general> - <type> - <title>: <concise result>
```
